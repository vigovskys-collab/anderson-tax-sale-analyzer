# Anderson County SC Tax Sale Analyzer v10.4

Key changes:
- Correct version label: v10.4.
- Failed/unreachable online lookups are NEVER classified as land.
- Added yellow **Unknown / needs verification** category.
- Map supports Land, House/structure, Mobile home, and Unknown filters.
- Added manual verification/correction so a user can record a confirmed outside source when an external site blocks automated access.
- County residential CLASS + IMPRV is treated as a **structure clue**, not absolute proof of a house.
- Existing exact County parcel, Google Maps, Street View, Zillow and Realtor links remain available.
